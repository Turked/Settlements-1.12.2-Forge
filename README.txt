See README.md for controls, setup, DataGen, configuration and implementation limits.
Run tools\Build.ps1 from PowerShell using a Java 8 JDK to build the mod.
The installable output is build\libs\Settlements-0.1.0.jar.

Generated resources are authored through the Java DataGen source, not by editing
JSON output. No original textures or 3D geometry are included; placeholders reuse
existing Minecraft assets.
