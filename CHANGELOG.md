# Settlements 0.1.0

- Named Settlements, authored by MechGaming, with mod ID `settlements`.
- Added persistent proposals, dimension-aware claims, membership, inboxes and operator zones.
- Added the virtual flag/raised-hand planner, controls, owner menus and in-world overlays.
- Unified the controls under K, named Settlements: toggle the flag planner outside claims or open the current settlement menu inside a claim. Removed the separate F menu binding.
- Added generated recipes, language, metadata and replaceable vanilla asset references.
- Added room-based NPC definitions and trades with a vanilla-rendered settler entity.
- Added optional tagged raids, explicit blueprints, inventory repair and bounded event restoration.
- Added consensual war rosters, lives/bed objectives, inventory wagers, annexation and scoped ghost protection.
- Added persistence/network/policy checks. Validated Forge 2860 and RLCraft initialization separately with external developer tools.

Full live-world RLCraft and multiplayer release checks remain listed in `docs/Verification.md`.
